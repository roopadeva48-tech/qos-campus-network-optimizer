2. Campus Traffic Priority Tiers

Traffic is categorized into 4 tiers following DiffServ (RFC 4594) standards.

Priority 1

Voice Communication (VoIP / SIP)

Real-time conversational audio. Handled via Strict Priority (LLQ) to keep delay strictly under 150ms.

DSCP EF (46)
Priority 2

Live Video Lectures (Zoom / Teams)

Interactive webinars and lectures. Guaranteed 50% minimum bandwidth to eliminate frame freezing.

DSCP AF41 (34)
Priority 3

LMS Portals & Web (Canvas / Moodle)

Online quiz submissions and portal browsing. Guaranteed 20% bandwidth to prevent session timeouts.

DSCP AF21 (18)
Priority 4

Bulk Downloads & Updates (ISOs / FTP)

Background file transfers. Managed dynamically via WRED to use leftover link capacity without congesting real-time traffic.

DSCP Best Effort (0)

4. Router Configuration Blueprint (Cisco IOS)

Ready-to-deploy Modular QoS CLI (MQC) configuration for campus routers.

Cisco IOS MQC Configuration 
! Define Class Maps
class-map match-any CM-VOICE
 match ip dscp ef
class-map match-any CM-VIDEO
 match ip dscp af41
class-map match-any CM-LMS
 match ip dscp af21

! Define Policy Map (LLQ + CBWFQ + WRED)
policy-map PM-CAMPUS-QOS
 class CM-VOICE
  priority 128
 class CM-VIDEO
  bandwidth percent 50
 class CM-LMS
  bandwidth percent 20
 class class-default
  bandwidth percent 10
  random-detect

! Apply to WAN Bottleneck Interface
interface GigabitEthernet0/1
 service-policy output PM-CAMPUS-QOS
