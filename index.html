Section 1: Service Characterization

Traffic Classification & Performance Objectives

Campus multi-service flows have fundamentally divergent physical network requirements. Voice requires deterministic bounded latency, video requires high throughput with low jitter, whereas web and bulk transfers rely on TCP elasticity.

P1 HIGHEST DSCP EF (46)

Voice / VoIP Communication

VoIP, SIP, Real-Time Interactive Audio
Target Bandwidth 32 – 64 kbps (G.711 / G.729)
Max Latency Cap < 150 ms (ITU-T G.114)
Max Jitter Cap < 30 ms
Packet Loss Tolerance < 1% max
Queue Allocation Strict Priority LLQ

Rationale: Human ear detects audio artifacts when delay exceeds 150ms. LLQ de-queues voice before any other class.

P2 HIGH DSCP AF41 (34)

Live Video Lectures & Webinars

Zoom, Microsoft Teams, Webex Broadcasts
Target Bandwidth 1.5 – 5.0 Mbps (720p/1080p)
Max Latency Cap < 220 ms
Max Jitter Cap < 50 ms
Packet Loss Tolerance < 1.5% max
Queue Allocation CBWFQ 50% Minimum

Rationale: Interactive video needs smooth bitrate. Drop rate above 2% results in pixelation and frozen keyframes.

P3 MEDIUM DSCP AF21 (18)

Web Browsing & LMS Portals

Canvas, Moodle, Blackboard, Academic APIs
Target Bandwidth Elastic / Bursty HTTP/HTTPS
Max Latency Cap < 2000 ms
Max Jitter Cap Tolerant (TCP Buffered)
Packet Loss Tolerance 0% (Guaranteed TCP)
Queue Allocation CBWFQ 20% Guaranteed

Rationale: Online exam submissions and quiz answers cannot time out or drop during high-stakes testing sessions.

P4 STANDARD DSCP BE (0)

Bulk Downloads & Background FTP

OS ISOs, Software Updates, Large Files
Target Bandwidth Opportunistic (10–20%)
Max Latency Cap Insensitive (Background)
Max Jitter Cap Insensitive
Packet Loss Tolerance 0% (TCP Handles Retries)
Queue Allocation Default BE with WRED

Rationale: Multi-gigabyte downloads consume spare link bandwidth but must yield immediately to real-time streams.

WRED Avoidance
Strict Priority

Low Latency Queuing (LLQ)

Assigned exclusively to Voice (DSCP EF). LLQ creates a strict priority hardware queue that is serviced ahead of all normal fair-queues. As soon as a voice packet arrives, the router interrupts normal round-robin cycles to serialize it immediately.

Anti-Starvation Guard: Governed by a hard policing rate (e.g. 128 kbps cap) to prevent misconfigured or malicious voice surges from starving lower data tiers.
Weighted Fairness

Class-Based WFQ (CBWFQ)

Guarantees minimum bandwidth allocations for non-realtime interactive data during link congestion periods:

  • Live Video (AF41): 50% guaranteed link slice.
  • LMS Portals (AF21): 20% guaranteed link slice.
  • General Web Traffic: 10% guaranteed link slice.

Unused bandwidth during quiet moments is dynamically shared across active classes.

Congestion Avoidance

Weighted Random Early Detection (WRED)

Enabled on TCP-heavy queues (LMS and Bulk Downloads). Unlike naive tail-drop (which drops entire bursts when buffers fill, triggering global TCP synchronization), WRED probabilistically drops single TCP packets early as queue thresholds rise.

TCP Backoff: Forces individual TCP senders to throttle their congestion windows smoothly without causing link underutilization.
Elastic Buffer

Best-Effort Dynamic Pool (BE)

Bulk downloads, ISO file grabs, and unauthorized file transfers consume dynamic unallocated capacity (10–20%).

When real-time classes peak (e.g. campus-wide live lecture start), background flows are instantly compressed to zero-impact levels without dropping video or audio frames.

#!/usr/bin/env python3
# Mininet + Linux Traffic Control (tc) QoS Dumbbell Setup

from mininet.net import Mininet
from mininet.node import Controller, RemoteController, OVSKernelSwitch
from mininet.cli import CLI
from mininet.log import setLogLevel

def run_qos_topology():
    net = Mininet(controller=Controller, switch=OVSKernelSwitch)
    c0 = net.addController('c0')

    # Add Ingress & Egress Routers/Switches
    s1 = net.addSwitch('s1')
    s2 = net.addSwitch('s2')

    # Add 4 Sender Workstations
    h_voice = net.addHost('h_voice', ip='10.0.1.1/24')
    h_video = net.addHost('h_video', ip='10.0.1.2/24')
    h_lms   = net.addHost('h_lms',   ip='10.0.1.3/24')
    h_bulk  = net.addHost('h_bulk',  ip='10.0.1.4/24')

    # Add Receiver Server
    h_recv  = net.addHost('h_recv',  ip='10.0.2.10/24')

    # Link Senders to Ingress Switch (100 Mbps access)
    net.addLink(h_voice, s1)
    net.addLink(h_video, s1)
    net.addLink(h_lms,   s1)
    net.addLink(h_bulk,  s1)

    # Bottleneck Link between s1 and s2 (10 Mbps throttled)
    net.addLink(s1, s2)
    net.addLink(s2, h_recv)

    net.start()

    # Apply Linux HTB (Hierarchical Token Bucket) on s1-eth5 (bottleneck link)
    print("*** Configuring Linux tc HTB Queuing Disciplines...")
    s1.cmd('tc qdisc del dev s1-eth5 root')
    s1.cmd('tc qdisc add dev s1-eth5 root handle 1: htb default 40')
    s1.cmd('tc class add dev s1-eth5 parent 1: classid 1:1 htb rate 10mbit')

    # Class 1:10 (Voice LLQ - Highest Priority)
    s1.cmd('tc class add dev s1-eth5 parent 1:1 classid 1:10 htb rate 128kbit ceil 256kbit prio 1')
    # Class 1:20 (Video - 50% BW)
    s1.cmd('tc class add dev s1-eth5 parent 1:1 classid 1:20 htb rate 5mbit ceil 10mbit prio 2')
    # Class 1:30 (LMS - 20% BW)
    s1.cmd('tc class add dev s1-eth5 parent 1:1 classid 1:30 htb rate 2mbit ceil 5mbit prio 3')
    # Class 1:40 (Bulk Best Effort - 10% + WRED RED)
    s1.cmd('tc class add dev s1-eth5 parent 1:1 classid 1:40 htb rate 1mbit ceil 10mbit prio 4')
    s1.cmd('tc qdisc add dev s1-eth5 parent 1:40 handle 40: red limit 1000000 min 30000 max 75000 avpkt 1000 burst 20')

    CLI(net)
    net.stop()

if __name__ == '__main__':
    setLogLevel('info')
    run_qos_topology()
# Discrete-Event QoS Queuing Simulation in Python
import simpy
import random
import numpy as np

class QoSNetworkModel:
    def __init__(self, env, bottleneck_bw_mbps=10.0, qos_enabled=True):
        self.env = env
        self.bw_bps = bottleneck_bw_mbps * 1e6
        self.qos_enabled = qos_enabled
        
        # Priority Queues (0=Voice EF, 1=Video AF41, 2=LMS AF21, 3=Bulk BE)
        if qos_enabled:
            self.server = simpy.PriorityResource(env, capacity=1)
        else:
            self.server = simpy.Resource(env, capacity=1)
            
        self.stats = {'voice_delays': [], 'video_drops': 0, 'video_total': 0}

    def packet_sender(self, name, p_type, priority, arrival_rate, packet_size_bytes):
        pkt_id = 0
        while True:
            # Poisson inter-arrival time
            yield self.env.timeout(random.expovariate(arrival_rate))
            pkt_id += 1
            self.env.process(self.transmit_packet(p_type, priority, packet_size_bytes))

    def transmit_packet(self, p_type, priority, size_bytes):
        arrival_time = self.env.now
        tx_duration = (size_bytes * 8) / self.bw_bps

        if self.qos_enabled:
            req = self.server.request(priority=priority)
        else:
            req = self.server.request()

        yield req
        wait_time = (self.env.now - arrival_time) * 1000 # in ms
        yield self.env.timeout(tx_duration)
        self.server.release(req)

        if p_type == 'voice':
            self.stats['voice_delays'].append(wait_time)

# Run discrete-event simulation
env = simpy.Environment()
model = QoSNetworkModel(env, bottleneck_bw_mbps=10.0, qos_enabled=True)
# Voice: 64kbps CBR
env.process(model.packet_sender('Voice', 'voice', 0, arrival_rate=125, packet_size_bytes=64))
# Video: 3.5Mbps Poisson
env.process(model.packet_sender('Video', 'video', 1, arrival_rate=364, packet_size_bytes=1200))
# Run for 100 seconds
env.run(until=100)
print(f"Mean Voice Latency (QoS): {np.mean(model.stats['voice_delays']):.2f} ms")
